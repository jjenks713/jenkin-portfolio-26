# josh-jenkin.com

Personal portfolio of Josh Jenkin, software engineer at Onboard.

A single static page: `index.html`, `styles.css` and `main.js`, with no build step. It's hosted on GitHub Pages from the `main` branch, and the custom domain is set in `CNAME`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

Push to `main`. GitHub Pages publishes it to https://josh-jenkin.com within a minute or two.
