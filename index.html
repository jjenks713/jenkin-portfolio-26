About

I'm a full-stack software engineer at Onboard, based in Bremerton, across the water from Seattle. I've been building for the web since 2018. At Onboard I helped replatform the stack from PHP and Laravel to ASP.NET and React with TypeScript, and modernized the resident portal with passwordless one-click sign-in. I also designed and built an internal email campaign tool, owning it from the MySQL schema to the AWS deploy. Working with design, product and backend teams, I've shipped hundreds of features and releases.

On the side, I keep a handful of small businesses online: a restaurant, an illustration press and a salon. I like handing someone a site they can run themselves, then sticking around as it grows.

Off the clock I'm a music producer and engineer, and a lifelong gamer who's now learning game design in Unity, using the same C# and .NET I write at work.

creepybutcutepress.comCode
Case study
Problem
The 2022 Next.js site showed the artwork, but it had no shop and no way to manage content outside the Contentful dashboard.
Built
A React and TypeScript frontend with all data loading in TanStack Query. An Express API on Cloud Run handles JWT login, role-based permissions and inventory in MongoDB, and writes to Contentful through its management API. Content-model changes ship as migration scripts.
Result
The owner manages artwork, shop items, prices and stock from an admin panel in the app. The shop and cart are still in progress, so they ship hidden behind a LaunchDarkly flag. I can test them in production, and launching will be a toggle, not a deploy.

2026

LinkedIn Noise Reducer & AI Overview Blocker

Two Chrome extensions that clean up pages people use every day: one hides promoted posts, anniversaries and job-change alerts, the other removes Google's AI Overview.

  • Manifest V3
  • Content scripts
  • MutationObserver
  • chrome.storage
Noise Reducer codeAI Overview Blocker code
Case study
Problem
Both sites render dynamically and change their markup often, so selector-based blockers break within weeks.
Built
Content scripts that watch the page with a MutationObserver and match on visible text labels and content patterns instead of class names. A popup toggle saves each setting to chrome.storage.
Result
Small, fast extensions with a maintenance guide that explains how to check for and fix markup changes.
